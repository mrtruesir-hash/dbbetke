How crash games like Aviator work

Aviator, JetX, Spaceman and Aviatrix all use the same basic idea: a multiplier climbs from 1.00x while a plane or rocket rises, and it can "fly away" at any moment. You place a stake before the round starts, then decide when to cash out — the longer you wait, the higher the multiplier, but the round can end at any second. Cash out before it flies away and you win your stake times the multiplier; if it flies away first, the round is lost. Auto-cashout lets you set a target multiplier in advance so you don't have to react in the moment, and live stats show recent rounds so you can see how the multiplier has been trending.
